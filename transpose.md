# Transpose ▲▼ pitch ▹ speed ▹ loop for videos
## Quick guide to the Google Chrome extension

**Transpose ▲▼ pitch ▹ speed ▹ loop for videos** is a free Google Chrome extension that allows you to adjust pitch, change speed, and loop segments of online music videos. This guide explains the installation, startup process, and the key features of this extension.

## Getting started

To install and launch the **Transpose ▲▼ pitch ▹ speed ▹ loop for videos** extension:

1. Open Google Chrome.
2. Click the ![Control](i-control.svg){height=25} icon and go to **Extensions** > **Visit Chrome Web Store**.
3. Search for "transpose".
4. Select **Transpose ▲▼ pitch ▹ speed ▹ loop for videos** from the search results.
5. Click **Add to Chrome**.
   A confirmation window appears.
6. Confirm your choice by clicking **Add Extension** in the pop-up to add the extension to the browser.
7. Open any website containing videos and click the ![Transpose](i-transpose.svg){height=25} icon on the taskbar to launch the application.

> **TIP:** Click the ![Extensions](i-extensions.svg){height=25} icon on the browser's taskbar and pin **Transpose ▲▼ pitch ▹ speed ▹ loop for videos** to the taskbar if needed.


## Using the extension

1. Open Google Chrome.
2. Navigate to the desired video.
3. Launch the extension by clicking the ![Transpose](i-transpose.svg){height=25} icon on the taskbar.
   This opens the extension interface.
   ![Extension interface](interface.png){width=300}
4. Use the control panel at the bottom of the interface to:
    - Restart playback
    - Rewind 5 seconds
    - Play or pause
    - Fast-forward 5 seconds
5. Adjust the Transpose, Pitch, Speed, and Loop settings as described in the following sections. 
   


### Using the transpose function

To change the key of the video, drag the **Transpose** slider or use the ![+](i-plus.svg){height=14} and ![-](i-minus.svg){height=14} buttons on its sides.

>**NOTE:** One step corresponds to one semi-note.

Use the ![Reset](i-reset.svg){height=25} button to return to the default setting.

### Using the pitch function

To fine-tune the pitch of the video, drag the **Pitch** slider or use the ![+](i-plus.svg){height=14} and ![-](i-minus.svg){height=14} buttons on its sides.

>**NOTE:** With the ![+](i-plus.svg){height=14} and ![-](i-minus.svg){height=14} buttons, the increment is 0.05 step (approximately 1.3 Hz). Dragging the slider provides a precision of 0.01 step (approximately 0.3 Hz).

Use the ![Reset](i-reset.svg){height=25} button to return to the default setting.

### Using the speed (tempo) function

To adjust the video's playback speed, drag the **Speed** slider or use the ![+](i-plus.svg){height=14} and ![-](i-minus.svg){height=14} buttons on its sides.
You can set any value between 25% and 400%.

>**TIP:** To precisely set the tempo, enter the desired BPM value in the **Tempo** field.

Use the ![Reset](i-reset.svg){height=25} button to reset.

### Using the loop function

Define two markers (timestamps) to loop the video between them.

1. To define a marker, click the ![Marker](i-marker.svg) icon while the video is playing.  
   **NOTE:** You can define or fine-tune a marker by entering its timestamp in the field next to the marker name. Use the format *mm:ss.s*.
2. Repeat this step for the second marker to define the end of the segment.
3. Click the ![Loop](i-loop.svg) icon to start looping the segment.  
   The two active timestamps are marked with ![Active marker](i-marker-active.svg), and the ![Active loop](i-loop-active.svg) icon indicates that looping is active.
4. Click the ![Active loop](i-loop-active.svg) icon again to stop looping.
 
#### Additional loop options

- Click the ![Repeat video](i-repeat.svg){height=25} icon to loop the entire video.
- Click the ![Add delay](i-delay.svg){height=25} icon to add a 3-second delay between loops.
- Click the ![Add marker](i-add.svg){height=25} icon to add more markers. You can loop the video between any two consecutive markers.
- Click the ![Sort markers](i-sort.svg){height=25} icon to sort markers by time (earliest to latest).

#### Marker operations

- Rename markers for easier navigation by clicking their name and entering a custom value.
- Jump to a marker by clicking the ![Jump to marker](i-jump-to-marker.svg) icon next to its timestamp.
- To delete a marker, hover over it and click the ![Delete marker](i-delete.svg) icon that appears.


### History

The extension automatically saves your settings and markers. Click the ![History](i-history.svg){height=25} icon in the extension header to view your recent videos.

#### Delete a video from the history

1. Hover over a video in the list.
2. Click the ![Delete history](i-delete-history.svg){height=25} that appears.
