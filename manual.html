Transpose ▲▼ pitch ▹ speed ▹ loop for videos

Quick guide to the Google Chrome extension

Transpose ▲▼ pitch ▹ speed ▹ loop for videos is a free Google Chrome extension that allows you to adjust pitch, change speed, and loop segments of online music videos. This guide explains the installation, startup process, and key features of this extension.

Getting started

To install and launch the Transpose ▲▼ pitch ▹ speed ▹ loop for videos extension:

  1. Open Google Chrome.
  2. Click the icon and go to Extensions > Visit Chrome Web Store.
  3. Search for “transpose”.
  4. Select Transpose ▲▼ pitch ▹ speed ▹ loop for videos from the search results.
  5. Click Add to Chrome.
    A confirmation window appears.
  6. Confirm your choice by clicking Add Extension in the pop-up to add the extension to the browser.
  7. Open any website containing videos and click the icon on the taskbar to launch the application.
TIP: Click the icon on the browser's taskbar and pin Transpose ▲▼ pitch ▹ speed ▹ loop for videos to the taskbar if needed.

Using the extension

  1. Open Google Chrome.
  2. Navigate to the desired video.
  3. Launch the extension by clicking the icon on the taskbar.
    This opens the extension interface.
  4. Use the control panel at the bottom of the interface to:
    • Restart playback
    • Rewind 5 seconds
    • Play or pause
    • Fast-forward 5 seconds
  5. Adjust the Transpose, Pitch, Speed, and Loop settings as described in the following sections.

Using the transpose function

To change the key of the video, drag the Transpose slider or use the and buttons on its sides.

NOTE: One step corresponds to one semi-note.

Use the button to return to the default setting.

Using the pitch function

To fine-tune the pitch of the video, drag the Pitch slider or use the and buttons on its sides.

NOTE: With the and buttons, the increment is 0.05 step (approximately 1.3 Hz). Dragging the slider provides a precision of 0.01 step (approximately 0.3 Hz).

Use the button to return to the default setting.

Using the speed (tempo) function

To adjust the video’s playback speed, drag the Speed slider or use the and buttons on its sides. You can set any value between 25% and 400%.

TIP: For precise tempo adjustment, enter the desired BPM value in the Tempo field.

Use the button to return to the default setting.

Using the loop function

Define two markers (timestamps) to loop the video between them.

  1. To define a marker, click the icon while the video is playing.
    NOTE: You can define or fine-tune a marker by entering its timestamp in the field next to the marker name. Use the format mm:ss.s.
  2. Repeat this step for the second marker to define the end of the segment.
  3. Click the icon to start looping the segment.
    4. The two active timestamps are marked with , and the icon indicates active looping.
  4. Click the icon again to stop looping.

Additional loop options

  • Click the icon to loop the entire video.
  • Click the icon to add a 3-second delay between loops.
  • Click the icon to add more markers. You can loop the video between any two consecutive markers.
  • Click the icon to sort markers by time (from earliest to latest).

Marker operations

  • Rename markers by clicking their name and entering a descriptive label (for example, start of chorus).
  • Jump to a marker by clicking the icon next to its timestamp.
  • To delete a marker, hover over it and click the icon that appears.
